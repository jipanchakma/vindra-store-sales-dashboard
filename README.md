Vindra Store Sales Dashboard

Every order in this dataset is a real customer making a real choice. This project is my attempt to listen to what a year of sales was trying to say.

The dashboard is built in Excel with pivot charts and slicers (Month, Category, Channel), so anyone can explore the story themselves.

Key Insights
Sales trend: Revenue peaked in March (~1.93M) and gradually declined toward year-end, with order counts following the same pattern.
Customers: Women account for 64% of sales and lead across adult, senior and teenage groups.
Geography: Maharashtra (2.99M) and Karnataka (2.65M) are the top-performing states.
Channels: Amazon (35%), Myntra (23%) and Flipkart (22%) dominate sales.
Fulfilment: 92% of orders were delivered; returns, refunds and cancellations were minimal.
Tools Used

Microsoft Excel (Pivot Tables, Pivot Charts, Slicers)

What I Learned

Clean data matters more than flashy charts, and a good dashboard answers questions before people have to ask them.
